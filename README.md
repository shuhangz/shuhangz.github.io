# Shuhang Zhang's Academic Homepage

This is my personal academic homepage built with the [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) template.

## About Me

I am an assistant professor at School of Geospatial Engineering and Science, Sun Yat-sen University. My research interests are photogrammetry, spatial analysis and view planning.

## Features

- Automatically update Google Scholar citations using GitHub Actions
- Responsive design for all devices
- SEO optimized
- Google Analytics support

## Local Development

To run this site locally:

1. Install Ruby, RubyGems, GCC and Make
2. Run `bash run_server.sh` to start the Jekyll server
3. Open http://127.0.0.1:4000 in your browser
